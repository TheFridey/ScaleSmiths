## Previously hidden functionality made visible in B2.10

The old toolkit marked all 14 items `builtIn: false`, so a partner with no founder record saw **Planned** for each, including features that already worked: referral codes, joint meetings, technical assistance, optional training, prospect registration and researched-prospect allocation. The new journey derives each status from the real record (see [B2-10-PARTNER-LAUNCH-REPORT.md](B2-10-PARTNER-LAUNCH-REPORT.md) §3).
